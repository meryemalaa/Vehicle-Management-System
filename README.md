# Vehicle-Management-System
Vehicle Management System

Description

A Java application designed to manage different types of vehicles, including regular cars, electric cars, and petrol cars.

The project demonstrates object-oriented programming concepts and provides a simple menu-driven interface for managing vehicle records.

Features

Add new vehicles.

Display all registered vehicles.

Remove vehicles by brand.

Support different vehicle types (Car, ElectricCar, PetrolCar).

Prevent duplicate vehicle entries.

Validate user input and vehicle data.

Save and load vehicle information using file handling.

Technologies Used

Java

Object-Oriented Programming (OOP)

Inheritance

ArrayList

Exception Handling

File Handling

Project Structure

Main.java – Main application and menu.

Car.java – Base Car class.

ElectricCar.java – Electric car class.

PetrolCar.java – Petrol car class.

VehicleFileManager.java – Handles saving and loading vehicle data.

How to Run

Install the Java Development Kit (JDK).

Clone or download this repository.

Open the project in Visual Studio Code.

Compile and run the application.
